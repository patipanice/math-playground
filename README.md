# Math Playground — คณิต A-Level ที่กดเล่นได้

เว็บทบทวนคณิตศาสตร์ประยุกต์ 1 (TCAS A-Level) แบบ **playground**: 24 เครื่องมือโต้ตอบ ครอบคลุม 16 บทตามหลักสูตร + คลังคำศัพท์อังกฤษ A-Level 188 คำ
ทฤษฎีเหลือบรรทัดเดียวต่อบท ที่เหลือคือลากเล่นเอง

**เปิดใช้งาน:** https://patipanice.github.io/math-playground/

## มีอะไรในนั้น

| บท | เครื่องมือ |
|---|---|
| เซต | เวนน์ไดอะแกรมกดเปลี่ยนนิพจน์ (เห็นกฎเดอมอร์แกนด้วยตา) |
| ตรรกศาสตร์ | สวิตช์ p, q + ตารางค่าความจริงสด 10 คอลัมน์ |
| อสมการ & ค่าสัมบูรณ์ | ตารางเครื่องหมายลากรากได้ · เส้นจำนวน \|x−a\| |
| เลขยกกำลัง | มอร์ฟกราฟ xⁿ ตั้งแต่ n = −3 ถึง 4 |
| ฟังก์ชัน | ตัวเลื่อนกราฟ a·f(x−h)+k · กระจกอินเวอร์สรอบ y = x |
| พาราโบลา | a, b, c → จุดยอด ราก ดิสคริมิแนนต์ |
| เอกซ์โพ & ลอการิทึม | bˣ กับ log_b x เลื่อนฐานพร้อมกัน |
| ตรีโกณมิติ | ลากมุมรอบวงกลมหนึ่งหน่วย → คลื่นวาดตัวเอง · เครื่องปั้นคลื่น |
| เมทริกซ์ | บิดระนาบด้วย [[a,b],[c,d]] · det = พื้นที่ |
| เวกเตอร์ | ลากลูกศร 2 ตัว → ดอต มุม โปรเจกชัน พื้นที่ |
| จำนวนเชิงซ้อน | ลาก z₁ z₂ เห็น "ขนาดคูณ มุมบวก" |
| ภาคตัดกรวย | วงกลม/วงรี/ไฮเพอร์โบลา/พาราโบลา + โฟกัส |
| ลำดับ & อนุกรม | แท่งพจน์ + เส้นผลบวกสะสม + S∞ |
| การนับ | สามเหลี่ยมปาสกาลกดได้ · เครื่องคิด nPr / nCr |
| สถิติ | ลากจุดข้อมูล 9 จุด → x̄, มัธยฐาน, s, box plot · โค้งปกติ 68/95/99.7 |
| แคลคูลัส | บีบ h → 0 เส้นตัดเป็นเส้นสัมผัส · ผลรวมรีมันน์เพิ่ม n |
| **คลังคำศัพท์** | 2 ชุดสลับกันได้: **ศัพท์อังกฤษ A-Level 188 คำ** (11 หมวด — กริยาวิชาการ, คุณศัพท์, นามนามธรรม, คำบอกน้ำเสียงผู้เขียน, คำเชื่อม, phrasal verbs, สำนวน, คู่คำที่คนสับสน, บทอ่านวิทย์-สิ่งแวดล้อม, บทอ่านสังคม-เศรษฐกิจ, prefix/suffix) และ **ศัพท์เทคนิคคณิต 128 คำ** · ค้นหาสด + กรองตามหมวด |
| **Flashcard** | การ์ดสุ่มลำดับ 3 โหมด (ศัพท์→ความหมาย / ความหมาย→ศัพท์ / นิยาม-ตัวอย่าง→ศัพท์) ให้คะแนนตัวเอง วนคำที่ยังไม่แม่น จำความคืบหน้าไว้ในเครื่อง |

ท้ายหน้ามีแผ่นสรุปสูตรรวมสำหรับปริ๊นก่อนสอบ

## เทคนิค

ไฟล์ HTML เดียว ไม่มี dependency ไม่มี build step ไม่มี CDN — กราฟทุกอันวาดสดด้วย Canvas 2D
มีโหมดสว่าง/กระดานดำ (ตามระบบ หรือกดสลับเองที่แถบซ้าย) และใช้งานบนมือถือได้
Flashcard จำความคืบหน้าด้วย localStorage (เก็บในเครื่องผู้ใช้ ไม่ส่งไปไหน)
คีย์บอร์ดใน Flashcard: `space` พลิกการ์ด · `1` ยังไม่ได้ · `2` จำได้
