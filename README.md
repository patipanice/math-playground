# Math Playground — คณิต A-Level ที่กดเล่นได้

เว็บทบทวนคณิตศาสตร์ประยุกต์ 1 (TCAS A-Level) แบบ **playground**: คณิตศาสตร์ 16 บท (เน้นเครื่องมือกดเล่น) + ชีววิทยา 18 บท (เน้นคำอธิบายเข้าใจง่าย) รวม 31 เครื่องมือโต้ตอบ พร้อมคลังคำศัพท์ 1,408 คำ และ Flashcard สุ่มท่องจำ
ทฤษฎีเหลือบรรทัดเดียวต่อบท ที่เหลือคือลากเล่นเอง

**เปิดใช้งาน:** https://patipanice.github.io/math-playground/

## มีอะไรในนั้น

| บท | เครื่องมือ |
|---|---|
| เซต | เวนน์ไดอะแกรมกดเปลี่ยนนิพจน์ (เห็นกฎเดอมอร์แกนด้วยตา) |
| ตรรกศาสตร์ | สวิตช์ p, q + ตารางค่าความจริงสด 10 คอลัมน์ |
| อสมการ & ค่าสัมบูรณ์ | ตารางเครื่องหมายลากรากได้ · เส้นจำนวน \|x−a\| |
| เลขยกกำลัง | มอร์ฟกราฟ xⁿ ตั้งแต่ n = −3 ถึง 4 |
| ฟังก์ชัน | ตัวเลื่อนกราฟ a·f(x−h)+k · กระจกอินเวอร์สรอบ y = x |
| พาราโบลา | a, b, c → จุดยอด ราก ดิสคริมิแนนต์ |
| เอกซ์โพ & ลอการิทึม | bˣ กับ log_b x เลื่อนฐานพร้อมกัน |
| ตรีโกณมิติ | ลากมุมรอบวงกลมหนึ่งหน่วย → คลื่นวาดตัวเอง · เครื่องปั้นคลื่น |
| เมทริกซ์ | บิดระนาบด้วย [[a,b],[c,d]] · det = พื้นที่ |
| เวกเตอร์ | ลากลูกศร 2 ตัว → ดอต มุม โปรเจกชัน พื้นที่ |
| จำนวนเชิงซ้อน | ลาก z₁ z₂ เห็น "ขนาดคูณ มุมบวก" |
| ภาคตัดกรวย | วงกลม/วงรี/ไฮเพอร์โบลา/พาราโบลา + โฟกัส |
| ลำดับ & อนุกรม | แท่งพจน์ + เส้นผลบวกสะสม + S∞ |
| การนับ | สามเหลี่ยมปาสกาลกดได้ · เครื่องคิด nPr / nCr |
| สถิติ | ลากจุดข้อมูล 9 จุด → x̄, มัธยฐาน, s, box plot · โค้งปกติ 68/95/99.7 |
| แคลคูลัส | บีบ h → 0 เส้นตัดเป็นเส้นสัมผัส · ผลรวมรีมันน์เพิ่ม n |
| **ชีววิทยา: เซลล์** | ผ่าเซลล์สัตว์/พืช คลิกออร์แกเนลล์ดูหน้าที่ · ออสโมซิสเลื่อนความเข้มข้นดูเซลล์บวม–แตก–พลาสโมไลซิส |
| **ชีววิทยา: พันธุศาสตร์** | ตารางพันเนตต์อัตโนมัติ โมโนไฮบริด / ไดไฮบริด / หมู่เลือด ABO พร้อมอัตราส่วนจีโนไทป์–ฟีโนไทป์ |
| **ชีววิทยา: DNA** | ถอดรหัส DNA → mRNA → กรดอะมิโน ตามตารางรหัสพันธุกรรมจริง มีปุ่มสุ่มสายและกลายพันธุ์ 1 เบส |
| **ชีววิทยา: เอนไซม์ & แสง** | กราฟอัตราการทำงานตามอุณหภูมิ / pH / ซับสเตรต · กราฟสังเคราะห์แสงหาปัจจัยจำกัด |
| **ชีววิทยา: ระบบนิเวศ** | จำลองผู้ล่า–เหยื่อ (Lotka–Volterra) กราฟวิ่งสด เห็นยอดผู้ล่าตามหลังยอดเหยื่อ |
| **ชีววิทยา: การแบ่งเซลล์** | ไล่เฟสไมโทซิส 5 เฟส / ไมโอซิส 9 เฟส ทีละขั้น เห็นโครโมโซมขยับและจุดที่จำนวนลดครึ่ง |
| **ชีววิทยา: วิวัฒนาการ** | เครื่องคิดฮาร์ดี–ไวน์เบิร์ก เลื่อน p แล้วดูสัดส่วน AA / Aa / aa เป็นกราฟแท่ง |
| **ชีววิทยา: บทอ่าน** | เคมีของชีวิต · การหายใจระดับเซลล์ · สังเคราะห์แสงเชิงลึก · พันธุศาสตร์นอกเหนือเมนเดล & พันธุประวัติ · เทคโนโลยี DNA · วิวัฒนาการ · ความหลากหลาย · พืช · ย่อยอาหาร & หายใจ · เลือด & ภูมิคุ้มกัน · ไต ประสาท ฮอร์โมน · สืบพันธุ์ & พฤติกรรม — ทุกบทมีตารางเทียบ ลำดับขั้น กล่องเปรียบเทียบง่าย ๆ และ "ข้อสอบชอบถาม" |
| **คลังคำศัพท์** | 3 ชุดสลับกันได้: **TGAT / A-Level 998 คำ** เรียงหมวด A–Z (ชนิดคำ + คำแปลไทย + ประโยคตัวอย่างครบทุกคำ) · **ชุดคัดสรรตามหมวดใช้งาน 188 คำ** (กริยาวิชาการ, คำบอกน้ำเสียงผู้เขียน, คำเชื่อม, phrasal verbs, สำนวน, คู่คำที่คนสับสน ฯลฯ) · **ศัพท์เทคนิคคณิต 128 คำ** — ค้นหาสด + กรองตามหมวด |
| **Flashcard** | การ์ดสุ่มลำดับ 3 โหมด (ศัพท์→ความหมาย / ความหมาย→ศัพท์ / **ประโยคเติมคำ**→ศัพท์ โดยซ่อนคำเฉลยในประโยคเป็น _____) ให้คะแนนตัวเอง วนคำที่ยังไม่แม่น จำความคืบหน้าไว้ในเครื่อง |

ท้ายหน้ามีแผ่นสรุปสูตรรวมสำหรับปริ๊นก่อนสอบ

## เทคนิค

ไฟล์ HTML เดียว ไม่มี dependency ไม่มี build step ไม่มี CDN — กราฟทุกอันวาดสดด้วย Canvas 2D
มีโหมดสว่าง/กระดานดำ (ตามระบบ หรือกดสลับเองที่แถบซ้าย) และใช้งานบนมือถือได้
Flashcard จำความคืบหน้าด้วย localStorage (เก็บในเครื่องผู้ใช้ ไม่ส่งไปไหน)
คีย์บอร์ดใน Flashcard: `space` พลิกการ์ด · `1` ยังไม่ได้ · `2` จำได้

แก้ไข: แก้ `index.html` แล้ว `git push` — GitHub Pages อัปเดตเองใน 1–2 นาที

## ที่มาของข้อมูลคำศัพท์

ชุด **TGAT / A-Level 998 คำ** เรียบเรียงจากเอกสาร “1,000 ศัพท์อังกฤษ TGAT / A-Level สำหรับ TCAS”
โดย **English TestLab** (englishtestlab-toeic.app) — แปลงเป็นข้อมูลสำหรับ flashcard ตัดคำซ้ำ 2 คำออก
ชุดคัดสรรตามหมวดใช้งาน 188 คำ และชุดศัพท์เทคนิคคณิต 128 คำ เรียบเรียงขึ้นใหม่สำหรับหน้านี้
