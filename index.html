    01เครื่องมือ: เวนน์ไดอะแกรม

    เซต

    กดชื่อนิพจน์ แล้วดูว่ามันระบายพื้นที่ไหน — พอเห็นพื้นที่ ก็ไม่ต้องท่องกฎเดอมอร์แกนอีก

    กดเปลี่ยนนิพจน์ → ดูพื้นที่ที่ถูกระบาย

    tool 01
    ลองข้อ 1กด (A ∩ B)′ แล้วกด A′ ∪ B′ สลับไปมา — พื้นที่ต่างกันไหม
    ลองข้อ 2กด A ∩ (B ∪ C) เทียบกับ (A∩B) ∪ (A∩C) นี่คือกฎการแจกแจง
    ลองข้อ 3หา 2 นิพจน์ที่ระบายพื้นที่ “นอกวงทั้งหมด” ได้เหมือนกัน
    ติดตัวไปn(A∪B) = n(A)+n(B) − n(A∩B)สับเซตทั้งหมด = 2nA − B = A ∩ B′
    02เครื่องมือ: สวิตช์ค่าความจริง

    ตรรกศาสตร์

    05เครื่องมือ: ตัวเลื่อนกราฟ + กระจกอินเวอร์ส

    ฟังก์ชันและการแปลงกราฟ

    ข้อสอบชอบถาม “กราฟนี้คือกราฟเดิมที่ถูกทำอะไร” — เลื่อน a, h, k ดูสัก 20 วินาที แล้วจะจำได้เองว่า h เลื่อนสวนทางเครื่องหมาย

    y = a·f(x − h) + k · เลือก f แล้วเลื่อนได้เลย

    tool 06
    f(x) ต้นฉบับหลังแปลง

    อินเวอร์สคือการพับกระดาษตามเส้น y = x

    tool 07

    ลากเมาส์บนภาพเพื่อเลื่อนจุดสีชมพูบน f แล้วดูจุดคู่ของมันบน f−1 — พิกัดจะสลับที่กันเสมอ (a,b) ↔ (b,a)

    ลองข้อ 1ตั้ง h = 2 — กราฟเลื่อนไปทางขวา แม้เครื่องหมายในวงเล็บเป็นลบ
    ลองข้อ 2ตั้ง a เป็นค่าลบ — กราฟพลิกกลับหัวรอบเส้นแนวนอน
    ลองข้อ 3ในเครื่องมือกระจก เลือก x² แล้วดูว่าทำไมต้องจำกัด x ≥ 0 ถึงจะมีอินเวอร์ส
    ติดตัวไปf(x−h)+k → เลื่อนขวา h, ขึ้น ka < 0 → พลิกแกน x(f−1∘f)(x) = x
    06เครื่องมือ: เครื่องปั้นพาราโบลา

    ฟังก์ชันกำลังสอง

    เลื่อน a, b, c แล้วจับตาดูค่า b² − 4ac ในกล่องล่าง — ตอนที่มันเปลี่ยนจากบวกเป็นลบ กราฟจะยกตัวขึ้นพ้นแกน x พอดี นี่คือเหตุผลว่าทำไมดิสคริมิแนนต์บอกจำนวนคำตอบได้

    y = ax² + bx + c · ดูจุดยอด ราก และดิสคริมิแนนต์สด ๆ

    tool 08
    กราฟจุดยอดราก (จุดตัดแกน x)
    ลองข้อ 1ตั้ง a = 1, c = 1 แล้วเลื่อน b ไปหาจุดที่รากเหลือตัวเดียว (b² − 4ac = 0)
    ลองข้อ 2ทำให้ดิสคริมิแนนต์ติดลบ — สังเกตว่าจุดยอดลอยพ้นแกน x
    ลองข้อ 3เลื่อน c ทีละหน่วย จุดยอดขยับแนวตั้งเท่ากับ c เสมอไหม
    ติดตัวไปจุดยอด x = −b/2ax = (−b ± √(b²−4ac)) / 2aผลบวกราก = −b/a · ผลคูณราก = c/a

    08เครื่องมือ: วงกลมหนึ่งหน่วย + เครื่องปั้นคลื่น

    09เครื่องมือ: เครื่องบิดระนาบ

    เมทริกซ์ 2×2 คือเครื่องบิดระนาบ และดีเทอร์มิแนนต์คือพื้นที่ของสี่เหลี่ยมหน่วยหลังถูกบิด เลื่อนตัวเลขจนพื้นที่เป็น 0 แล้วดูว่าเกิดอะไรขึ้น — นั่นคือตอนที่อินเวอร์สหายไป

    ลองข้อ 3ทำให้ det ติดลบ — ระนาบถูกพลิกด้าน เหมือนส่องกระจก
    ติดตัวไปdet = ad − bcA−1 = 1det[[d, −b], [−c, a]]det = 0 ⇒ ไม่มีอินเวอร์ส
